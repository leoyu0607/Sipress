## 修正

- **Windows 上 SIP 接收中止（os error 10054）**：用 UDP 時，若 SIP 伺服器的 port 沒有程式在聽或被防火牆擋下，對方會回 ICMP「port 無法連線」。Windows 會在下一次接收時把它報成 `os error 10054`（遠端主機已強制關閉一個現存的連線），原本程式收到後就結束 SIP 接收，之後伺服器的回應都收不到，看起來像啟動後卡住。現在只記一行警告並繼續接收（Linux 對應的 `ECONNREFUSED` 也一樣處理）。民眾端、座席端與註冊測試都適用。

## 排查提示

log 出現「SIP 伺服器 … 回報 port 無法連線（ICMP）」代表當下送出的封包沒有送到。請確認 SIP 伺服器的 IP、port、傳輸方式（UDP / TCP）與中間的防火牆設定。

| 平台 | GUI | CLI |
|---|---|---|
| Windows x64 | `sipress-gui-windows-x86_64-setup.exe`（安裝版）、`-installer.msi`、`-portable.exe`（免安裝） | `sipress-windows-x86_64.exe` |

| Linux ARM64 | — | `sipress-linux-arm64` |

macOS 免安裝檔是單一執行檔：下載後先執行 `chmod +x sipress-gui-macos-*-portable`；若出現「無法驗證開發者」，執行 `xattr -d com.apple.quarantine sipress-gui-macos-*-portable` 後再開啟。每個檔案都附有 `.sha256` 可核對。
