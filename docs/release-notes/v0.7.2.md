## 整合報告

- **「門檻」改稱「警戒值／警戒線」**：交給客戶的整合報告不再出現「門檻」一詞，避免讀者誤以為數值要碰到那條線才算達標。判定表的欄名、結論文字、圖例與圖下統計改稱「警戒值」，橘黃色虛線改稱「警戒線」。圖表上的虛線只標數值（例如 `80%`），不再寫「門檻 80%」。判定規則與預設值不變；GUI 與 CLI 的設定仍叫「判定門檻」（`--thresholds`）。

## GUI 改進

- **匯出選單**：標題列原本的五個「↓ JSON / CSV / HTML / 數據 / 對照」按鈕合併成一個「匯出」選單，暫時不能匯出的項目會直接寫出原因，也可以用鍵盤操作（#31）。
- **即時圖表可暫停**：「暫停」會凍結圖表畫面，資料仍在背景接收；開始新一次測試或切換民眾／座席時自動恢復。圖表上方加了一行文字摘要（目前、平均、最高、最低與時間範圍），點選圖表後可用 ← → / Home / End 逐點查看（#33）。
- **側欄可調寬度**：拖曳側欄右緣調整寬度（240–440 px），雙擊恢復預設，下次開啟會記住（#33）。
- **指標除了顏色也有文字分級**：ASR、ERR%、REG、掉包率、Jitter 與 MOS 旁加上「良好 / 注意 / 偏低」「優 / 普通 / 差」等文字。還沒發出任何通話時不分級，所以剛開始測試不會出現紅色的 0%（#32）。
- **易讀性**：文字對比在深色與淺色主題都達 WCAG AA，最小字級 11 px；表單欄位都有對應標籤，可收合的區塊能用鍵盤操作。「開始測試」不能按時，原因直接列在側欄上方（#30）。
- **其他**：「開始測試／停止測試」改成實心大按鈕；圖示統一成同一套 SVG；滑桿範圍會跟著輸入框的數值延伸；數字欄位可輸入五位數；音檔提示更正為實際支援的格式（WAV 16-bit PCM 或 G.711、raw G.711）；視窗寬 960 px 時標題列不再擠掉關閉按鈕；視窗標題改為「sipress — SIP 壓測工具」（#30–#33）。
