## 重點

- **整合壓測報告**：交給客戶的正式報告，包含結論、測試條件、通話量與聲音品質圖表，可加上受測主機的 CPU、記憶體、磁碟資料，依門檻判定「通過 / 未通過」，可直接輸出 PDF。GUI 標題列的「整合報告」或 CLI `--integrate` 產生（#26、#27、#28）。
- **MOS（jitter buffer 模擬）**：模擬話機 50 / 200 ms 的固定緩衝，延遲超過緩衝的封包視同遺失。原本的 E-Model MOS 在 Jitter 低於 150 ms 時不扣分，高負載時容易偏樂觀；判定改用 200 ms 版本。
- **10 秒時間軸**：每 10 秒一段，每段只算該段新增的封包，短暫的品質下降不會被整通電話平均掉。GUI 測試中的聲音品質改顯示「近 10 秒」。

## 新功能

### 整合報告

- **來源**：壓測數據檔 `<時間>_result.json`。CLI 加 `--html` 時自動寫出，GUI 用標題列的「↓ 數據」匯出；也可以直接用 GUI 最近一次的測試結果。數據檔不含任何密碼。
- **報告內容**：
  1. 結論：總判定、自動產生的結論文字（含品質超過門檻的時間點）、各項判定表。
  2. 測試條件：模式、伺服器、時長、CPS、並發、語音編碼與受測環境備註。
  3. 通話量：並發通話數、CPS、接通率。
  4. 聲音品質：MOS（含並發通話數疊圖）、掉包率（整體與最嚴重的單通）、Jitter（平均與 P95）。
  5. 受測主機資源（有匯入時）：每台主機的規格、CPU、記憶體、每顆磁碟的 Disk Queue／忙碌率雙軸圖。
  6. 指標說明。
- **判定**（門檻可調整）：

  | 項目 | 判定值 | 預設門檻 |
  |---|---|---|
  | MOS（jitter buffer 200 ms） | 每通電話的 P5 | ≥ 4 |
  | 掉包率 | 整體 | ≤ 0.5% |
  | Jitter | 每通電話的 P95 | ≤ 30 ms |
  | CPU 使用率 | 10 秒取樣的 P95 | ≤ 70% |
  | 記憶體使用率 | 10 秒取樣的 P95 | ≤ 80% |
  | Disk Queue（每顆磁碟） | 10 秒取樣的 P95 | ≤ 2 |

- **圖表**：每張圖都有平均線、橘黃色門檻虛線，超過門檻的時段以紅色底色標示，圖下列出平均、最高 / 最低與超標時段數。配色參考 Zabbix、VoIPmonitor，時間軸在開啟報告時換成當地時間。
- **主機資料**：匯入主機 agent 主控台「效能」頁的「匯出分析資料 (ZIP)」，或單台主機的 `metrics.csv`，依測試開始時間自動對齊。磁碟忙碌率需要新版主機 agent（`disk_util_<磁碟>` 欄位），舊版只畫 Disk Queue。
- **輸出**：依 A4 排版。GUI 可「儲存 HTML」「瀏覽器開啟」「匯出 PDF」；匯出 PDF 使用本機的 Chrome 或 Edge，找不到時可用瀏覽器開啟後按報告右上角「列印 / 另存 PDF」。
- **CLI**：

  ```bash
  ./sipress -s 192.168.1.100:5060 --rtp -c 300 --cps 5 -d 2h --html
  ./sipress --integrate reports/<時間>_result.json \
    --host-metrics metrics-20261028-0958-1205.zip \
    --report-notes "受測系統 SIPX 4.2" --pdf
  ```

  `--thresholds <JSON>` 可覆寫門檻，例如 `{"cpu_pct":60,"mos":3.8}`，未寫的欄位用預設值。

### 聲音品質統計

- 新增 `mos_jb50`、`mos_jb200`（每通平均）與晚到封包數。延遲基準取最近 30 至 60 秒內最小的延遲，會跟著兩端時鐘的漂移移動。
- 最終報告新增 `fine_timeline`（10 秒時間軸，每段含掉包率、最嚴重單通、Jitter 平均 / P95、MOS 平均 / 最低 / P5）、`started_at`（測試開始時間，UTC）、`call_quality`（每通電話最終 MOS 的分布）。

### 座席註冊有效期

- 新增 `--register-expires`（GUI「註冊有效期」，預設 3600 秒），在有效期的 2/3 時重新註冊，與一般 IP 話機相同。原本固定要求 240 秒、每 180 秒刷新，SIPX 每次都會產生一個 CTI 註冊事件。

## 調整

- 速覽 HTML 報告：整體評分改用 MOS（jitter buffer 200 ms）；掉包率顯示到小數 2 位，顏色改為 0.5% 以內正常、1% 以內注意（原本 3% 以內都顯示正常）；指標名稱寫明算法，報告最後加上「指標說明」。
- GUI 右側聲音品質：測試中顯示近 10 秒的值，結束後顯示整場的值，標題旁標示是哪一種；新增 MOS·JB 一列；掉包率顏色同上。

## 安全性

- GUI「↓ JSON」匯出不再包含座席帳號密碼、撥號認證密碼與座席流程密碼。帳號匯出（CSV）仍包含密碼，用於搬移帳號。
- 匯入的主機資料視為不可信：只把需要的兩個檔案讀進記憶體、不解壓到磁碟；限制大小（防壓縮炸彈）、主機 / 磁碟 / 欄位 / 列數；不合理的數值當缺值；所有文字跳脫後才放進報告。

## 升級注意事項

- 最終報告與即時快照只新增欄位，沒有移除或改名。
- 速覽 HTML 報告的整體評分改看 jitter buffer 200 ms 的 MOS，同一次測試的評分可能比舊版低。
