## 新功能

- **雙端整合報告**：整合報告可以同時放入民眾端與座席端的測試結果。每一端只能量測自己收到的聲音，所以 MOS、掉包率、Jitter 分兩個方向判定：民眾聽到的（座席 → 民眾）與座席聽到的（民眾 → 座席），**兩個方向都在警戒值內才算通過**。第 4 節的圖表也分兩組畫，座席端的時間軸會依兩端的測試開始時間對齊到民眾端（#37）。
  - GUI：「整合報告」視窗新增「最近一次雙端測試（民眾端＋座席端）」，兩端都跑完時預設選它；選壓測數據檔時可一次選兩份。
  - CLI：`--integrate` 可給兩份數據檔，順序不拘：`./sipress --integrate caller_result.json agent_result.json`
  - 只放一端的報告也會標出量測的是哪個方向。

## 修正

- **MOS P5 不再在新通話剛接通時掉到 1**：接通後到收到對方第一個封包之間，原本會把已送出的封包全部算成掉包；10 秒時段若剛好在這時結算，這通電話就被記成 MOS 1，讓整合報告的 P5 紅線在通話交替時頻繁掉到 1，平均也被拉低（例如 10 通中一通被誤算，平均從 4.41 變成 4.07）。現在送出未滿 2 秒且尚未收到封包時先不計入時段；超過 2 秒仍沒收到，才當作單向無聲計入。最終判定用的是整通電話的 MOS，先前的通過 / 未通過結果不受影響（#37）。
- **整合報告的 MOS 圖移除「MOS（E-Model）平均」線**：這條線和「平均」點線同為灰色、名稱相近，容易混淆。圖說補充：紅色底色只依主線（每張圖的第一條線）判斷，灰色點線為主線的全程平均，並說明 P5 的意思（#37）。

## 下載

| 平台 | GUI | CLI |
|---|---|---|
| Windows x64 | `sipress-gui-windows-x86_64-setup.exe`（安裝版）、`-installer.msi`、`-portable.exe`（免安裝） | `sipress-windows-x86_64.exe` |
| macOS Apple Silicon | `sipress-gui-macos-arm64-installer.dmg`、`-portable`（免安裝） | `sipress-macos-arm64` |
| macOS Intel | `sipress-gui-macos-x86_64-installer.dmg`、`-portable`（免安裝） | `sipress-macos-x86_64` |
| Linux x64 | `sipress-gui-linux-x86_64-installer.deb`、`-portable.AppImage` | `sipress-linux-x86_64` |
| Linux ARM64 | — | `sipress-linux-arm64` |

macOS 免安裝檔是單一執行檔：下載後先執行 `chmod +x sipress-gui-macos-*-portable`；若出現「無法驗證開發者」，執行 `xattr -d com.apple.quarantine sipress-gui-macos-*-portable` 後再開啟。每個檔案都附有 `.sha256` 可核對。
