## 重點

- **端到端對照報告**：把民眾端每通電話和座席端收到的來電配對，算出漏接率、排隊與分配延遲、ACD 改派次數與雙向音質，產生一份合併的 HTML 報告。
- **座席行為模擬**：響鈴延遲、拒接、不接、主動掛斷、休息時間、通話中忙線，可以實際測到 ACD 的重新分配。
- **CLI 支援座席模式**：`--mode agent --accounts <帳號檔>`，不開 GUI 也能壓測座席端。
- **持續時間分兩端設定**：座席端可以先開、比民眾端晚關。

## 新功能

### 端到端對照報告

- 配對方式：
  1. 先用 SIPX 的 `P-CIN-CallId`。同一通電話的每一段（回給主叫的 180 / 200、送到座席的 INVITE）都帶相同的值；SIP Call-ID 則每段都不同。
  2. 拿不到時，改用主叫號碼 + 時間窗（預設 120 秒）。
- 民眾端新增「每通不同主叫號碼」：第 n 通使用「主叫號碼 + n」並保留位數。用主叫號碼配對時可以一對一，不會混淆。
- 報告內容：漏接率（另列完全沒有座席收到的通數）、分配延遲與座席接起延遲（平均 / P50 / P95 / MAX）、ACD 改派、雙向 MOS，以及漏接明細、每通明細、未配對的座席來電。
- **GUI**：雙端執行後，標題列的「↓ 對照」匯出報告。民眾端完成後即可匯出，座席端仍在執行也沒關係。
- **CLI**：兩端各加 `--trace-file` 寫出追蹤紀錄，再用 `--correlate <檔案A> <檔案B>` 合併。可搭配 `--format json|csv|table` 與 `--html`。

```bash
./sipress -s 10.0.0.1:5060 --mode agent --accounts agents.csv -d 0 --trace-file agent.json
./sipress -s 10.0.0.1:5060 --from 0912000000 --from-seq --to 168168999 -c 20 --cps 2 -d 60 --trace-file caller.json
./sipress --correlate caller.json agent.json --html
```

### 座席行為模擬

GUI 的座席端設定與 CLI 都可以調整：

| 設定 | CLI | 說明 |
|---|---|---|
| 響鈴後接聽 | `--ring 2-5` | 送 180 Ringing 後隨機等幾秒才接（`N` 或 `最小-最大`） |
| 主動掛斷 | `--talk 30-90` | 接聽後隨機幾秒由座席送 BYE |
| 拒接 % | `--reject-pct 10` | 響鈴後回 486 Busy Here |
| 不接 % | `--no-answer-pct 10` | 一直響鈴，等 SIPX 逾時 CANCEL 改派（回 487；120 秒仍未取消回 480） |
| 休息時間 | `--wrap-up 5` | 通話結束後這段時間內的來電回 486 |
| 通話中忙線 | `--busy-in-call` | 已有通話或響鈴中時，新來電回 486 |

### CLI 座席模式

- `--mode agent --accounts <檔案>`：帳號檔格式與 GUI 匯入相同。GUI 帳號清單的「匯出 CSV」可以直接使用。
- `--account-domain`、`--ack-timeout`、`--bye-timeout`。
- 按 Ctrl-C 或在 TUI 按 `q`，會先送 `REGISTER Expires=0` 解除註冊再結束。`-d 0` 不限時間時，也能用這兩種方式停止。
- GUI 的 CLI 預覽在座席模式會產生對應指令。

### 其他

- 持續時間分成民眾端、座席端各自設定。雙端啟動時，如果座席端會比民眾端先結束，事件記錄會警告。

## 修正

- 雙端執行中無法切換「民眾端 / 座席端」分頁，畫面會卡在其中一端。
- 民眾端與座席端的 SIP log 檔名相同：雙端在同一秒啟動時，兩端會寫進同一個檔。
- 事件記錄在出現失敗後每秒重複寫一次失敗統計，洗掉其他事件；現在只在失敗數增加時記錄。
- 側欄版面：座席行為欄位的數字被截斷、「測試執行中」橫幅在捲動時與欄位重疊、帳號統計文字被擠成直排。

## 升級注意事項

- **SIP log 檔名**：民眾端改為 `logs/*_caller.sip.log`，座席端仍是 `logs/*_agent.sip.log`。若有腳本依檔名讀取 log，請一併調整。
- **持續時間設定**：舊版只有一個共用的持續時間，升級後會同時套用到兩端；座席端新的預設值是 0（不限時間）。
- **新增參數全部預設關閉**：座席行為參數、`--from-seq`、`--busy-in-call` 不設定時，行為與 v0.4.0 相同。
- **時鐘同步**：民眾端與座席端在不同電腦執行時，請先校時（NTP），否則對照報告的延遲數值會有誤差；報告出現負值即代表時鐘不同步。
